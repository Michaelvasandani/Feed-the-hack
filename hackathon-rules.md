# Hackathon Rules

Build a product for creators. Ship it by sunset. 🚀

Free stack, real data, live demos, and a jury of leading tech entrepreneurs, investors and content creators!

Every attendee gets credits to build their hackathon stack across all three partners:

- 🎥 **Oriane API**: social video intelligence across TikTok & Instagram
- 💜 **Lovable**: prompt to product
- ⚡ **GMI Cloud**: hosting & GPU compute
- 🎬 **[Compound.mov](https://compound.mov/)**: Create more better videos

📍 Hosted at Amplitude HQ in SF. What better place to build data-first products?

## The Challenge

Build the tool a creator, or an agency running 50 of them, uses on Monday.

Trend copilot, hook analyzer, influencer finder, competitor watchtower, content playbook, social trend monitoring, review collector from UGCs... anything that comes to mind, leveraging social media video data!

Devs, marketers, creators, all in. Come solo or as a team.

No code needed: Lovable's got you, or we'll pair you with a builder.

## Tips & Tricks

*From the Oriane.xyz Video Intelligence blast:*

- If you use Lovable to build with their credits, use Claude to do the heavy building first, then drop the HTML of your project into Lovable to make it functional. Lovable charges a lot of credits during the iteration process.
- Dump the JSON file from the Oriane API documentation into Lovable or your AI builder, along with the API key, so it fully understands how the API works: https://www.oriane.xyz/api
